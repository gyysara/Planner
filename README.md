# Планнер задач для аккаунт- и гейм-менеджеров

Закрытая веб-страница: календарь задач команды (аккаунт-менеджер + его гейм-менеджеры) с цветами проектов,
рамками по сроку, уведомлениями в Telegram и в браузере со звуком и недельным отчётом.

## Возможности
- **Вход и регистрация**: имя, логин, пароль, роль, аватарка. Регистрация только по **коду приглашения** (`INVITE_CODE`).
  Гейм-менеджер ничего не видит, пока аккаунт-менеджер не привяжет его на странице «Команда».
- **Календарь** «Месяц / Неделя». Клик по пустой дате или часу — форма задачи с подставленной датой; клик по карточке — развёрнутая задача.
- **Карточка**: фон в цвете проекта, название, аватарка и имя исполнителя. Рамка по сроку:
  больше 5 дней — обычная, ≤ 5 дней — жёлтая, ≤ 2 дней — красная, срок прошёл — тёмно-красная с ⚠, у завершённых — без подсветки.
- **Статусы** «Новая / В работе / Завершено»; для «Завершено» обязателен «Результат», задача попадает в недельный отчёт.
- **Проекты**: название, цвет, привязанные гейм-менеджеры. **Команда**: привязка/отвязка гейм-менеджеров.
- **Отчёты** за неделю пн–вс: «Отчёт за 12.10–18.10: завершена задача "…", результат: …», плюс просроченные.
- **Уведомления** исполнителю и автору: о новой задаче — сразу; за 5 дней, за 2 дня и в день дедлайна — в выбранный
  пользователем час (по умолчанию 10:00 по Минску). Каналы: Telegram и всплывающее окно со звуком в открытой странице
  (системное уведомление браузера — если разрешено).
- **Настройки**: аватарка, мелодия (4 стандартные или своя), час напоминаний, подключение Telegram.

## Права
| | Аккаунт-менеджер | Гейм-менеджер |
|---|---|---|
| Видит задачи | свои и всех своих гейм-менеджеров | свои и других гейм-менеджеров своей команды |
| Назначает | себя или любого своего гейм-менеджера | только себя (в проектах, куда привязан) |
| Проекты, команда | создаёт, меняет, удаляет | только просмотр |

Чужие команды друг друга не видят (проверяется на сервере, ответ 404).

## Безопасность
- Всё содержимое и все файлы (`/api`, `/files`, `/assets`) — только после входа.
- Пароли — `scrypt` с солью; сессия — случайный токен в httpOnly-cookie, в базе хранится только его хэш.
- Ограничение попыток входа, защита от CSRF (служебный заголовок), CSP, `X-Frame-Options`.
- Закрыто от индексации: `robots.txt`, `<meta name="robots">`, заголовок `X-Robots-Tag`.
- Ключ Telegram-бота и код приглашения — только в `.env` на сервере.
- В Telegram уходит только название, проект, срок и исполнитель — без описания.

## Структура
```
server/            Express-сервер, SQLite (встроенный node:sqlite), уведомления, Telegram
shared/deadline.js расчёт рамок и стадий напоминаний (общий для сервера и браузера)
public/            страница (HTML/CSS/JS без сборки)
assets/audio/      стандартные мелодии (генерируются scripts/gen-audio.py)
assets/img/        аватар по умолчанию
data/              база и загруженные аватарки/мелодии (создаётся при запуске, не в git)
deploy/LIGHTSAIL.md пошаговая публикация на AWS Lightsail
```

## Запуск локально
Нужен Node.js 22.13+.
```bash
npm install
INVITE_CODE=test-invite npm start      # http://localhost:3000
npm test                               # автотесты, включая сценарий из ТЗ
```

## Проверка (тестовый сценарий, только тестовые данные)
1. Зарегистрировать тестового аккаунт-менеджера и гейм-менеджера «Иван Тестов», привязать на «Команде». Гейм-менеджер загружает аватарку.
2. Создать «Проект Альфа» фиолетового цвета, поставить Ивану задачу через 6 дней (провайдер «TestGames»).
   Карточка фиолетовая, видна у обоих; пришло уведомление в Telegram и всплывающее окно со звуком.
3. Дедлайн через 4 дня — жёлтая рамка и напоминание; через 1 день — красная и напоминание; вчера — тёмно-красная с ⚠.
4. Иван переводит задачу в «В работе», затем в «Завершено» с результатом. Задача появилась в отчёте за неделю.
5. Пользователь другой команды эту задачу не видит.

Шаги 1–5 автоматизированы в `test/scenario.test.js`.

## Границы прототипа
Нет восстановления пароля и подтверждения почты, разбора митов, мобильного приложения, повторяющихся задач,
вложений и комментариев, выгрузки отчётов, истории изменений. Всплывающие уведомления работают при открытой
странице (или если браузер разрешил уведомления); при закрытом браузере не гарантируются — для этого есть Telegram.
